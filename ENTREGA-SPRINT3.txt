COMO EXECUTAR
---------------------------------------------------------------
1) Backend - porta 8080
   cd API-Motiva
   mvn spring-boot:run
   Conferir: curl http://localhost:8080/sensores

2) App - Expo
   cd mobile
   npm install
   npx expo start

BASE_URL usada pelo app (src/services/api.ts)
   Web / iOS .......... http://localhost:8080
   Emulador Android ... http://10.0.2.2:8080
   Celular fisico ..... http://<IP-DA-MAQUINA>:8080

ENDPOINTS CONSUMIDOS PELO APP
---------------------------------------------------------------
GET  /medicoes                  lista o historico (mais recentes primeiro)
GET  /medicoes/sensor/{id}      historico de um sensor
GET  /sensores                  catalogo de sensores
POST /medicoes/simular          botao "SIMULAR COLETA" (valor gerado no servidor)
POST /medicoes                  registra uma leitura com valor informado
